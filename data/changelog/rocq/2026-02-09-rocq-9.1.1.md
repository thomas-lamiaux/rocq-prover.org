We have the pleasure of announcing the first patch release of Rocq 9.1.1. The
main changes are:

  - Fixed an anomaly when defining a sort polymorphic inductive without enabling
    Universe Polymorphism.
  - Fixed compatibility with OCaml 5.4 with warnings as errors

The full list of changes is available [here](/doc/V9.1/refman/changes.html#changes-in-9.1.1) for more details.

---

## Installation Instructions

The base compiler can be installed as an opam switch with the following commands:

```bash
opam update
opam switch create 4.14.1
opam install rocq-prover rocq-core=9.1.1
```
The source code for the release is also directly available on:

* [GitHub](https://github.com/rocq-prover/rocq/releases/download/V9.1.1/rocq-9.1.1.tar.gz)
